# 本机数据库连接服务

此服务仅监听 `127.0.0.1:4319`，供本机编辑器和发布页读取 MySQL、PostgreSQL。需要 Node.js 20 及以上。

```sh
cd local-db-gateway
pnpm install
pnpm setup
pnpm start
```

首次 setup 会在此目录创建权限为 `0600` 的 `config.json`，其中包含随机服务令牌；将 `token` 值复制到编辑器的数据连接面板。已有配置不会被覆盖。也可通过 `DATA_WIND_DB_CONFIG` 指定配置文件，`DATA_WIND_DB_PORT` 指定监听端口。

在右侧“数据”中选择 MySQL / PostgreSQL，填写服务地址与令牌，点击“新建连接”。连接可在该面板中编辑或删除；编辑时密码留空会沿用已保存的密码。服务只向浏览器返回连接名称、类型和非密码连接信息，不返回密码。连接信息和数据库密码保存在本机配置文件；项目与发布包仅保存服务地址、连接标识和 SQL。令牌保存在浏览器当前会话；新发布页可按提示重新输入。请使用只具备所需表读取权限的数据库账号。

Webhook 接收地址也由该服务在右侧“数据”中创建。选“Webhook 推送”后，复制生成的 URL 给发送端；发送端可 POST JSON 或 `application/x-www-form-urlencoded` 表单。实时更新会覆盖上一批数据，累积更新会保留最近设置数量（最多 5000 行）。接收数据最多占 1 MB，并在服务重启后清空。Webhook URL 含随机标识，是发送权限凭据；不要公开分享。此服务只监听本机回环地址，发送端必须能访问创建地址的同一台电脑。

服务默认允许 `127.0.0.1` 和 `localhost` 的 5173、4173 端口作为网页来源。若发布页使用其他来源，需将其完整来源加入配置文件的 `allowedOrigins`，并确保浏览器允许该页面访问本机 HTTP 服务。配置修改即时生效。

查询限制为单条无注释、无分号的 `SELECT`，在只读事务中执行，最多返回 1000 行、1 MB，查询超时 10 秒。结果可在面板表格中分页查看并导出 CSV。表或视图选择会生成带标识符转义的 SQL。服务不负责启动数据库；目标 MySQL 或 PostgreSQL 必须自行运行并允许连接。
