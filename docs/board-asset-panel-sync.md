## 一、整体结构（面板 = 覆盖层）

山海鲸把「rail + 模板条 + 抽屉」做成一个覆盖在画布上的整块面板（vn-stack，宽 716px），顶部一行 header 同时容纳 rail 搜索框与主题 tab：

```
┌─ asset-panel（覆盖层，z>画布）────────────────────────┐
│ [🔍搜索组件]  │  深色 │ 浅色 │ 资产库        ↻ ⛶ │ header h=41
├──────────┬──────────────────────────────────────────┤
│ rail 184 │  [模板条 162]  抽屉 354   （拓扑/套件）      │
│ #1e1e1e  │  ─────────────────────────────────────    │
│ 全部 1212│  抽屉 532（其余分类，3 列网格）              │
│ 图表   85│                                            │
│ …        │                                            │
└──────────┴──────────────────────────────────────────┘
```

- 收起态：仅 49px 图标 rail（图标上、文字下，行高 52，fs12），无搜索框、无 header。
- 点一级分类 → rail 展开为 184px（顶部搜索框 + 每行右侧计数），同时抽屉覆盖层打开；再点激活分类收起。
- 面板不挤压画布（纯覆盖）。

## 五、与旧实现的差异（破坏点）

1. 看板态抽屉头由「{分类}素材 + ×」改为「深色/浅色/资产库 + ↻/⛶」，关闭 = 再点激活的 rail 分类（与山海鲸一致，无 × 按钮）。
2. 搜索框从抽屉内部移到 rail 顶部（仅展开态可见）；`palette-hint` 提示文案删除。
3. 「全部」分类不再显示小节标题与「我的素材」区块（用户素材统一入「资产库」tab）。
4. 3D 编辑态（AssetLibraryPanel / modelCategories rail）不在本次范围，维持既有实现。
