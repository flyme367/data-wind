# 3D 地表 / 水体

进入 **3D 编辑 → 地表 → 水体**，点击海洋、湖泊、泳池、河流或浅水模拟添加水面。五类入口参考[山海鲸地表水体](https://www.shanhaibi.com/docs/v1/ct4ckx4ofdqqpo2n)，浅水材质和出水点参考[官方浅水模拟介绍](https://www.shanhaibi.com/article/v1/pz9l028wzc05qlt3/)。无需 Blender，也不依赖外部贴图或模型文件。

## 编辑

水体归入图层树的“地表”。右侧可调整宽度、深度、水位、波浪高度、波长、速度、风向、材质颜色、折射颜色、散射颜色、最大透明深度、不透明度、粗糙度和泡沫。水位是组件局部水面中心在世界坐标中的 Y 值；三轴旋转和缩放仍通过“变换”设置。调整宽深保持水位。

- **海洋**：512 × 512 米有界水面，默认较大的长波。
- **湖泊**：椭圆水面，默认微波。
- **泳池**：矩形水面，默认细小波纹。当前生成水面，不生成池壁、池底或开挖地形。
- **河流**：沿局部控制点生成带状水面。可在平面图拖点，或输入局部 X/Z；支持插入、删除控制点及调整河宽，纹理条纹沿路径流动。
- **浅水模拟**：64 × 64 高度场，支持运行、暂停、重置、初始水深及最多 8 个注水/排水点。正流量为注水，负流量为排水，流量单位 m³/s；位置和半径随组件宽深缩放。

参数、河道路径和出水点参与撤销、重做、复制、分组、锁定、显隐、项目自动保存、JSON 备份、二进制快照及本地发布。为控制负载，每场景最多 16 个水体，其中最多 4 个浅水模拟。项目保存参数；重新打开时从初始状态运行，不保存 GPU 的瞬时流场。

## 渲染与 Bevy

复用项目现有 **Bevy 0.20 Core3d / DwGpuPlugin**，水体与地形、模型共用相机、实例缓冲和光照。上游 [`bevy_water`](https://github.com/Neopallium/bevy_water) 的兼容表目前对应 Bevy 0.18，并依赖其 PBR 材质通道；本项目使用自定义 wgpu 30 场景通道，因此没有添加该依赖或降级 Bevy。原有 Avian 地形碰撞继续独立工作。

全场景共享一套 65 × 65 网格，每个水体一次 indexed draw。WGSL 完成波浪位移、河道路径映射、法线细节、Fresnel 天空反射、方向光高光与雾。相机移动不生成或上传水面网格。

存在可见水体时，不透明地形与模型先绘制；随后复制场景颜色，将 Depth24Plus 深度通过一个 compute pass 转存为 R32Float。水面只采样副本，避免纹理同时作为附件和采样资源。没有可见水体时保留原来的单场景通道，不增加颜色或深度复制。按场景深度计算透明衰减、折射与岸边泡沫，折射偏移落到前景物体时回退原坐标。反射使用天空近似，没有平面反射或 SSR；互相交叠水面的透明排序采用组件中心距离近似。

CPU 兼容路径采用 24 × 24 水面网格，提供动画、透明颜色和三角形拾取，不执行场景深度折射。GPU 编辑拾取采用静态水位的粗网格，湖泊和河道按各自轮廓拾取，浅水按模拟域拾取，不逐帧读回波峰或干湿边界。

## 浅水计算

采用两阶段虚拟管道高度场方法：第一阶段根据相邻水位、重力、河床高程和历史流量计算四向出流，按本格可用水量限制总出流；第二阶段收集邻格出流、加入源/汇，更新水深与流速。反射边界不向域外排水，空格排水会截断到零。源项按离散覆盖面积归一化，位于边角的源也保持总流量；极窄覆盖不足一个网格时落到最近采样点。

GPU 使用 ping-pong storage buffers，每帧最多 4 个子步，每子步两次 compute dispatch。步长受实际帧间隔和网格间距限制，长帧最多推进 0.1 秒，极小网格会减慢模拟时间。没有每帧 CPU 网格重建、地形遍历或流场读回。

初始化和场景编辑时，沿水面局部竖直方向采样可见地形的缓存拾取网格。初始河床不低于设定水深；高于初始水位的地形保持干燥，阻挡水流。地形、组件变换或初始水深变化会更新河床并重置模拟；材质、暂停、波浪和出水点编辑保留现有流场。暂停停止水量流动，独立的风浪和材质波纹仍按波浪速度播放；速度设为 0 可停止风浪。资源库中标注为“船舶”的模型会按可见水体水位自动抬高，并保留最多 0.3 米的静态吃水；潜艇不自动浮起。当前没有逐帧浮力、船体摇摆或三维流体交互，普通模型也不作为水流障碍物。这是场景可视化高度场，不提供经过水文标定的工程预测。

## 验证

- `frontend/src/tests/water.test.ts`：五类组件、编辑历史、分组锁定、数量上限、参数校验、快照、渲染线协议与大坐标。
- `engine-rs/probe/tests/water.rs`：封闭水域水量、边角注水、排水非负、河床阻挡、轮廓拾取、缓存；显式 GPU 测试绘制五类水面，并核对 GPU 流场与 CPU 参考求解、暂停和重置。
- `engine-rs/probe/tests/shaders.rs`：WGSL 有效性、752 字节水体 uniform 与 384 字节帧 uniform 布局。
- `cd frontend && pnpm test:water:wasm`：加载生产 CPU WASM，验证五类水面的真实像素、动画、拾取及截图状态隔离。

真实 GPU 测试：`cd engine-rs && cargo test -p native-probe --test water gpu_water -- --ignored`。
