# 看板套件

看板编辑器的「套件」使用参考目录的 13 个主题和 872 个条目。主题、分类、顺序、名称和缩略图来自同一次目录快照。点击或拖入时才读取对应模板，保留原有父子图层、位置、尺寸、素材、状态和静态数据。插入、移动、尺寸调整与参数修改可撤销。套件可以保存到本地资产库后再次插入。

右侧样式面板使用从 85 类组件及其继承链静态提取的 3,698 条字段定义，并补充列表项背景和折线阴影等动态生成的字段；定义包括字段分组、下拉选项和可静态求得的默认值。菜单和下拉框的自定义选项支持逐行编辑、添加、删除和排序，修改时保留对应的默认项及联动值。颜色编辑支持透明度和渐变色标，文本字体分为样式、发光和投影设置。`kitOptionDefinitions.json` 保留了 42 类组件的默认示例数据。数据页支持字段选择、汇总、编辑模板数据、导入文件以及绑定实时数据源，导入后仍保留原有套件配置。动态数据字段可以绑定到组件属性；筛选支持指定行、指定范围、直接判断以及在“数据 → 数据条件”中新建的组合规则，并在字段映射前执行。组合规则支持数据源、项目参数和行号，组内为“与”、组间为“或”。图表、列表、表格、菜单和下拉框的选中项可按同源字段或跨源同名字段联动筛选；菜单和下拉框支持独立配置联动字段及自定义联动值。发出和接收方向分别配置黑白名单，兼容原始组件路径，复制套件时会重映射名单。交互页提供已映射的规则和原始配置。代码页可检查场景对象和随模板保存的原始脚本。

原始参数随项目保存，渲染参数转换后交给现有 Rust 看板。文字、图片、渐变、菜单与按钮状态、选项卡切换、图表和指标使用同一条预览及导出路径；指标数值与单位可分别设置字体、颜色和偏移，预览时支持数字递增和数据更新过渡；新版百分比图读取绑定字段的首条值，支持条形、柱形、环形角度、文本格式、条形及环形渐变，以及条形和环形分片的数量、间隔和背景；图片支持延迟、旋转方向、闪烁和循环间隔；单行和多行文字支持展示动画及循环间隔。菜单与下拉框可以使用自定义选项或数据字段，数据更新和筛选后同步重建选项；下拉框支持提示项、默认项、背景和字体设置、搜索、选项滚动、多选、多值筛选和仅选中选项时收起，以及由 `label`、`value`、`children` 组成的 JSON 树形选项、节点展开及按层级设置联动字段。调整套件容器尺寸时，子组件按各自的固定边距、居中、双边固定或缩放模式布局，嵌套容器也逐层计算。预览和发布使用“响应式自适应”时，同样根据窗口尺寸计算组件布局，且不修改编辑坐标。表格支持字段顺序、表头、行列样式、条件颜色和行点击。列表按分组字段去重，支持排序、垂直／水平／网格排列、自动轮播、分页、滚轮切换、项背景和行点击；单条及整页切换支持平滑移动，内容、背景及点击区域裁剪在列表内；子组件数据按分组字段匹配，未匹配的组件保留各自完整数据。发布包按项目引用收集本地套件资源。

时间组件补充了原站动态生成的预设格式选项，画布按照所选的固定时区计算日期、时间和星期，并支持常见的自定义日期时间标记；未选择自定义格式时不会使用遗留的自定义文本。

天气组件可在右侧选择省市，按今天、明天、后天或实况查询高德天气。Key 列表按顺序尝试，同城同服务模式共享请求。Rust 画布应用图标位置、尺寸和背景、文字排列、温度连接符和单位样式、风力与风向以及各项偏移。31 个天气分类可指定自定义图标，未配置的分类使用内置绘制。测试使用模拟服务响应，模板没有可用于实况联调的 Key。静态发布包默认清空天气 Key，发布对话框可选择包含。 [山海鲸天气组件](https://www.shanhaibi.com/docs/v1/cozuh0l9hic7degk/) · [高德天气接口](https://lbs.amap.com/api/webservice/guide/api-advanced/weatherinfo) · [城市名称与区划代码数据](https://github.com/yescallop/areacodes)

桑基图按节点字段和流量字段映射原始行，连线透明度进入画布。箱型图按绑定列计算五数概括，应用箱体宽度、边框和填充色。甘特图读取任务、起止日期和进度，并绘制日期刻度、计划与完成颜色。河流图按日期和分类组织数据，可绘制原模板中的四个系列，并应用图形留白与边框。现有项目重新打开时会从保存的原始数据重新映射这四类图表。

右侧属性的扩展菜单支持条件样式、调用代码示例和生成数据字段。代码示例使用本项目脚本环境的 `dw.setOption`。条件样式调用「数据 → 数据条件」中的规则，可以引用项目参数及数据源，并配置所有条件均不匹配时的样式。多条规则匹配时取列表中第一条。运行时评估规则并将有效值送到画布，编辑器和发布页使用同一路径。

静态模板包由 `frontend/scripts/sync-reference-kits.py` 转换。运行 `python3 frontend/scripts/sync-reference-kits.py --verify` 可检查目录和本地资源。清单位于 `frontend/public/kits/sync-report.json`，已验证 872 个模板、9,417 个图层和 2,633 个不同的资源文件引用，包含 8 个大型模型的原始文件。「古镇」的柳树和垂柳笔刷目录保留原始文件名和成员引用。 [参考编辑器](https://workspace.shanhaibi.com/#/project/layer?projectId=r8lqwtlat9bdwtxkqdbuh7sxbjfgvyq5)

按钮样式面板按默认、点击、悬停和选中状态组织，状态开关关闭时也可以预先编辑样式；文字对齐、内边距、偏移、字间距、字体样式、发光及实线／虚线边框进入画布。悬停和点击可按配置播放水波纹，但颜色、缓动和边界裁剪仍需与原站逐帧比对。菜单按选项原始键匹配独立样式，编辑或排序选项时同步更新样式关联，文字、边框和背景图片设置进入画布；经典网格按按钮尺寸居中，并支持逐项偏移、旋转及溢出裁剪；滚动布局支持水平／垂直方向、展示数量、滚轮和可拖动滚动条，滚动动画细节仍需继续对照。长文字支持省略；允许取消选中时右键菜单项会清除当前选中以及对应的联动和选中传递，允许重复触发时再次点击当前项可触发元素点击交互。套件图片解码期间不在图形上显示加载占位文字；列表新出现的同源图片复用已解码资源，减少轮播时的闪烁。

18 个城市场景组件在画布上默认使用原版预览图。右侧可检索和编辑场景中的相机、天空、材质等对象，已提取 33 类对象的 1,529 项配置定义，修改和状态覆盖会保存并支持撤销。7 个场景含有默认启用且可读取的网格，可以在右侧选择「预览场景几何」，切换鸟瞰视角、拖动旋转、滚轮缩放并点击模型定位到场景对象。预览读取模型和上级模型组的位置、旋转和缩放。「画布显示几何」可将相同的 Rust 渲染结果用于画布、预览和静态发布。`frontend/scripts/prepare-kit-model-previews.py` 使用 gltfpack 1.3 和 Pillow 为 6 份大型 GLB 和「春江蓝-地图」中采用 glTF 数据的 OBJ3 生成轻量预览，包含简化后的网格及缩小后的纹理。模板仍包含原始文件。Rust 按像素绘制模型自带的基础色和自发光贴图，处理纹理重复、镜像和边缘夹取、透明裁切与混合，并按深度遮挡和命中。右侧已匹配的材质可覆盖基础色、基础色强度、透明模式、alpha、发光颜色与强度，以及仅在夜晚生效。材质的独立基础色、透明度和发光图片贴图可覆盖原模型，支持选择原始 UV 集合、调整 UV 缩放和偏移、调整贴图强度，并可将黑白图用于透明度。`frontend/scripts/prepare-kit-texture-previews.py` 为 4 张超大贴图生成最长边 1,536 像素的预览副本，原文件仍随模板保存。可读取模型的材质支持法线和金属粗糙度贴图、切线空间和物体空间法线、背面剔除、禁用光照及无光自亮。金属粗糙度贴图按 glTF 的绿通道和蓝通道解释，法线和金属粗糙度按线性数据采样。直接高光使用 GGX 近似。场景辉光、泛光、环境反射、植被笔刷和专有模型仍待接入。 [山海鲸场景模型](https://www.shanhaibi.com/docs/v1/fw3skn7osu23gs5p/) · [鸟瞰相机](https://www.shanhaibi.com/docs/v1/oa4awvd05ga4tx7v/) · [PBR 材质](https://www.shanhaibi.com/docs/v1/gm17ptb54wr6vaps/) · [glTF 材质规范](https://registry.khronos.org/glTF/specs/2.0/glTF-2.0.html#materials)

原始包仍有 26 条素材引用无法解析。部分套件引用的原始数据条件定义没有包含在模板包内，需要重建并重新绑定。原站脚本使用原站运行时 API，当前以源码形式保存。菜单、下拉框、表格和列表支持按选项值或字段接收选中传递。树形下拉的复杂选中联动、列表过渡和复杂图表的细节仍需逐项对照。
