# 3D 地表 / 地形

水体组件见 [3D 地表 / 水体](water.md)。

进入 **3D 编辑 → 地表 → 地形**，点击平地、丘陵、山地、沙丘或雪山即可添加。图层树中的“地表”分组可选择根图层地形；普通分组内的地形保留原有分组关系。右侧提供宽度、深度、起伏高度、随机种子、岩石与积雪颜色、雪线、细节层级及碰撞设置。修改起伏高度会沿地形局部 Y 轴移动中心，保持底部位置。

“导入高度图”接受 10 MB 内的 PNG、JPEG、WebP，按像素亮度转换成最多 257 × 257 的方形采样。黑色对应低处，白色对应高处。采样数据随项目存入 IndexedDB 二进制快照、JSON 备份及本地发布包，不依赖原图片路径。图像解码采用浏览器的 8 位颜色通道，不保留 16 位 PNG 原始高程精度；非方形图片会缩放到方形。可以随时恢复预设地形。

不需要 Blender。高度场适合连续地表，洞穴、倒悬和隧道内部需要独立模型。

较大地形在定位后会拉远相机；若场景雾距离较短，可在场景设置中提高雾距离，以便查看完整地形。

## 渲染

- Bevy 0.20 的 Core3d 调度中使用现有自定义 WebGPU 通道。
- 全场景共享一套 65 × 65 顶点网格、中心索引和去除中心区域的环形索引。每块地形固定 **2 次 indexed draw**：中心一层、外环按层级实例化。默认 6 层提交 38,912 个三角形，覆盖矩形边界时有部分退化三角形。
- WGSL 将相机转换到地形局部坐标，按每层网格离散对齐。外环内边缘跟随细一级的对齐中心，外边缘顶点聚拢到父网格；先过渡坐标再采样高度，保持相邻层边缘重合。
- 单张 R32Float 高度纹理由顶点阶段手动双线性采样，不依赖可过滤浮点纹理扩展。GPU 在高度采样前进行整块地形包围球的视锥判断，细粒度三角形仍由硬件裁剪。
- 片元导数生成法线；坡度混合岩石，海拔和坡度共同控制积雪。程序纹理随屏幕导数衰减，降低远处闪烁；接收现有方向光模型阴影。
- 相机移动只更新既有帧 uniform，不重构或上传网格/高度图。高度场和拾取网格在场景内容变化时缓存重用。地形仍参与编辑器已有的 CPU 可见性统计，因此不声称整个应用 CPU 开销为零。
- CPU 兼容渲染采用独立的 32 × 32 网格；GPU 拾取使用缓存的 64 × 64 网格，支持三轴旋转和非等比缩放。这两条简化路径不等同于 GPU 各 LOD 的逐三角形精度。

## Bevy 生态与碰撞

采用 [Avian 0.8](https://github.com/avianphysics/avian/tree/v0.8.0) 的 `PhysicsPlugins`、静态刚体和 `Collider::heightfield`，只启用 `3d`、`parry-f32`，不启用默认调试绘制和额外并行特性。Avian 0.8 与 Bevy 0.20 兼容，复用工作区已有 Parry 0.31。

“地形精度 → 地形碰撞”默认关闭。开启后以轨道相机关注点为流式加载中心，在每块地形局部坐标中保留邻近的 3 × 3 个 64 米碰撞块，每块仅 16 × 16 个网格单元。超出地形边界的块不生成，远离地形、隐藏、删除或关闭碰撞时释放实体。只有跨块、地形数据或变换改变时重建，渲染网格不参与物理模拟。现有编辑器模型仍按原编辑流程工作；碰撞块供 Avian 物理实体使用，不会自动把普通模型变成动态刚体。

未直接引入通用地形插件的原因是版本与渲染架构：上游 [`bevy_terrain`](https://github.com/kurtkuehnert/bevy_terrain/blob/main/Cargo.toml) 使用 Bevy 0.14，[`bevy_mesh_terrain`](https://github.com/ethereumdegen/bevy_mesh_terrain/blob/main/Cargo.toml) 使用 Bevy 0.16。它们不能直接接入当前 Bevy 0.20 的自定义场景通道。

## 范围与验证

每场景最多 16 块地形，每块 3–8 个细节层级。当前为有界高度场，没有 GIS 瓦片流式加载、虚拟纹理、洞穴体素或材质笔刷。

`frontend/src/tests/terrain.test.ts` 覆盖场景历史、锁定、显隐、高度图线协议和项目快照。`engine-rs/probe/tests/terrain.rs` 覆盖环形覆盖面积、跨原点和负坐标的接缝、双线性高度采样、变换拾取和高度场缓存；`shaders.rs` 校验 WGSL 与 uniform 布局。

地形测试还会创建原生 WebGPU 设备，使用生产 `TerrainRenderer` 真实绘制并读回像素。本机已验证这一通道，生成 [768 × 512 GPU 离屏预览](../artifacts/terrain-gpu.webp)。`terrain_physics.rs` 中的 Avian 测试覆盖高度场坐标轴、比例、碰撞块复用和释放。

GPU 像素测试需要硬件适配器，默认跳过，可在 `engine-rs` 中执行 `cargo test -p native-probe --test terrain gpu_clipmaps -- --ignored`。

`cd frontend && pnpm test:terrain:wasm` 直接加载生产 CPU WASM，验证前端高度图编码、实际地形像素变化、拾取及截图不覆盖实时拾取状态。

本次已通过 208 项前端测试、71 项 Rust 验证（含显式运行的 GPU 像素测试）、生产 WASM 通信与地形测试，以及三个 WASM 产物和前端生产包构建。Lint / Clippy 仍有警告，全仓格式检查仍有存量差异；新增地形 Rust 模块格式检查通过。浏览器连接不可用，本次未完成菜单与属性面板的浏览器实点验收。
