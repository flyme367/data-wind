# 图表素材与配置

参考山海鲸编辑器的图表目录提供 85 个素材入口。项目以已有图表几何为基础区分预设、系列数量和配色；素材名称、示例数据与实例配置均随场景保存。编辑画布、预览和 PNG 导出共用 `data-wind-cpu` 的 egui 绘制，WebGPU 看板通过 bevy_egui 绘制同一几何。素材卡片使用轻量 SVG 预览，不能作为最终画布的像素级快照。

右侧图表属性按类型显示当前可用的选项：数据颜色、图形文本、坐标轴、图例，以及柱宽、曲线、扇区角度、仪表范围、热力色块等图形参数。桑基图另有节点宽度、间距和连线透明度；动态条形图与路径动画可调整周期和播放状态。配置保存在各节点的 `data.chart`，连续编辑在场景 Worker 中逐字段合并，并支持撤销；替换静态数据或应用实时数据时保留该实例的图表配置。

普通图表的颜色、图形文本、图形形状等分组直接显示在右侧样式面板中，顺序与参考编辑器相近；折线与双轴图使用标签切换主系列和右轴或折线文本。坐标轴面板按轴线、刻度线、刻度值、轴名称和网格线分组。套件组件保留原始配置，坐标轴提供 X、Y 与适用图表的右轴切换，并显示已支持的右轴设置。

普通二维笛卡尔图表可分别配置 X、Y 网格线开关和颜色，并可添加最多 32 条数值辅助线，设置数值、线型、颜色、宽度、虚线长度、文字颜色和偏移。套件的辅助线开关及每条线的原始配置映射到同一画布；辅助线位于图形下方，超出当前数值轴范围时不绘制。瀑布图、动态条形图、箱型图、子弹图、路径图、河流图、散点图、气泡图和 3D 柱图使用专用绘制路径，暂不提供这些新增选项。

普通二维笛卡尔图表可分别设置两轴及右轴刻度的字号、颜色、旋转角度、字体样式、文字截断宽度和外发光，以及四边内边距；套件中的相应设置会映射到画布。字体家族目前区分等宽和比例字体，粗体与外发光使用多层绘制近似。折线和面积图可设置两侧留白，关闭后首尾数据点、分类刻度和网格位于绘图区边缘；也支持实线、虚线，以及实心或空心圆、方块、圆角方块、三角形和菱形数据点。分类着色图表支持添加、删除颜色并循环使用调色板；未编辑过调色板的旧实例保留原有回退配色。

普通折线和面积图可选择显示全部或指定数量的数据项，并可去除零值：选择“跳过”时连接前后的有效点，选择“分段”时在零值处断开，点击命中仍返回原始数据行。可为每个系列单独设置线型、平滑、粗细、点形状、图片与阴影；统一设置也支持数据点图片和阴影。各系列可独立启用流光，设置形状、颜色、大小、尾迹长度和运行周期；有可见流光时画布按帧更新，暂停动画时停止更新。套件中的相应系列选项映射到同一绘制方式，图片按系列加载和释放。阴影和流光尾迹使用多层半透明图形近似，渐变圆和具体动画效果仍需继续与参考样式核对。

普通二维笛卡尔图表的 X、Y 轴可分别开关刻度文字、轴线和刻度线，设置轴线样式、宽度、颜色、点线间隔及刻度线长度、宽度和颜色；两轴网格线也支持设置宽度和实线或虚线。旧实例未配置轴线和刻度线时保持原有外观，套件组件则转换其原始选项。

普通二维图表的数值轴支持数值或百分比显示、小数位、补零及计数单位；百分比格式将原始比例乘以 100，百分比堆叠图已有的百分数不再重复放大。数值小于 1 时按实际范围缩放，百分比堆叠同样按实际合计计算。X、Y 轴名称可单独设置文字、字号、颜色和偏移，对应套件选项会映射到相同绘制路径。

普通二维柱图、条形图和双轴柱形可添加直接条件样式：按原始行字段比较数值或文本，为全部或指定系列覆盖颜色；规则按顺序取首个匹配项，缺少字段时不匹配。命中规则的柱形使用条件纯色。引用山海鲸已有数据条件、渐变条件色及专用图形的条件样式尚未接入。

普通二维图形文本支持数值或百分比、文字偏移、旋转、跟随图形颜色及单独的单位字号和颜色。柱形、条形和双轴柱形还可选择内部、外部或顶部位置，设置文本间距、垂直偏移、隐藏零值和分类名称前缀；横向分组及堆叠条形会分别绘制各系列的文本。双轴图和普通折线、非堆叠面积图的右轴系列可独立设置文本显隐、格式、位置、文字及单位样式；旧实例未配置时沿用原有图形文本设置。顶部位置当前按绘图区顶部或条形上方近似绘制，单位字体家族和粗斜体尚未接入。

普通二维柱图、条形图、折线、面积图和双轴图提供排名文本：可设置字体样式、文字模板、显示范围、距离、矩形或带箭头背景、图片背景及背景大小，颜色支持不透明度。纵向图在绘图区顶部按分类排列，横向图在右侧排列；套件图表的原始排名选项映射到同一渲染路径，图片通过画布资源加载并可随项目保存。当前按每个可见分类的可见系列总和降序排名，最大值和最小值包含并列项，自定义数量取前 N 项；缩略轴启用时对当前范围内的行计算。字体家族当前只区分等宽与比例字体，具体字体、并列排名和缩略轴规则与参考的完整一致性仍需进一步核对；区间图和专用图形尚未接入排名文本。

普通折线及非堆叠面积图可指定右轴首个系列，之后的系列共用右轴独立数值范围；双轴图的折线系列使用右轴范围。普通折线和非堆叠面积图支持负数数据，左右数值轴可分别使用自动范围或设置最小、最大刻度值；自定义范围支持按数值或数量设置刻度间隔，刻度文字、刻度线和网格线同步变化，过密刻度会限量绘制。自定义范围外的图形按绘图区裁剪；无效范围回退为自动范围。跨越零值的面积和缩略轴预览分别绘制零线上下的区域，点击仍返回原始负数和行索引。右轴支持轴线、刻度线、刻度文字、基本数字格式、轴名称和网格线。套件的左右轴字段及对应选项会映射到这些设置。图表仍最多使用三个数值系列；双轴图自定义范围和对数类型尚未接入。

普通及分组柱图、条形图也支持负数和数值轴自定义范围。柱形和条形从零基线向对应方向绘制，负值的外部文本和端点位于图形末端；自定义范围会裁剪图形、悬停高亮和点击区域。图形柱状图、区间图、堆叠图和双轴图仍使用原有路径。

普通二维笛卡尔图表可启用缩略轴，设置初始数据范围、位置、滑块和数据区域的颜色及大小；参考套件中的相应选项也会映射到该渲染器。编辑画布和导出使用保存的初始范围；预览与播放时可拖动两侧滑块调整范围，或拖动选中区域整体平移。拖动只影响运行时，场景同步保留该范围，退出预览或修改初始范围会重置。筛选后点击数据项仍返回原始行索引和数据。缩略轴沿用普通图表最多 30 行的限制；专用绘制路径暂不支持。

图例支持顶部、底部、左右侧共 12 个对齐位置，图形形状、大小、文字颜色、最大文字数及项间隔；预览中调整位置后仍可点击图例切换数据。提示信息可配置背景颜色和图片、内边距、圆角、图标、位置，以及名称、数值、标题和单位的独立文字样式；数值格式支持百分比、千分位、小数位和补零，支持右轴的独立格式与单位。普通折线、面积和双轴图及相应套件组件悬浮绘图区时按最近的分类汇总可见系列，并可配置水平、垂直辅助线及标签。套件原始选项和图表交互动作使用同一套渲染配置。二维饼图、环图和玫瑰图可调整大小和描边，并将图形文本显示为数值或占比，可设置小数补零。部分旧图表的默认图例位置及最多显示六个分类的限制仍保留；手动选择图例位置可调整现有图例的位置。

图例文字支持字体选择、粗斜体、下划线、删除线、字符间距、固定文本宽度及发光颜色、程度和偏移。图例可切换为翻页类型；内容超出可用尺寸时按图例实际尺寸分页，预览中可以用前后按钮切页，切页后仍可点击当前图例项切换数据。按钮文字也支持字体样式，图标大小、间距、可用或禁用颜色和左右背景图片可配置；套件中的对应选项映射到同一绘制路径。翻页模式下分类图例可以访问全部已绘制分类。字体目前区分比例和等宽两类，文字发光通过多次半透明绘制近似。

套件中的图表也会将支持的原始选项映射到同一渲染器，包括图例位置及图形、间隔、文字样式，折线点形状，以及提示框颜色、位置和内边距。参考套件中尚未接入的选项仍以原始配置保留，不能视为已经完成视觉或行为复刻。

图表通过 `data.rows` 接收数据。除普通的 `name`、`value`、可选的 `value2` / `value3` 外，特殊图形使用：

- 桑基图：`{ "source": "页面", "target": "首页", "value": 20 }`，也接受 `节点1`、`节点2`、`数值`。
- 箱型图：`{ "name": "A", "min": 10, "q1": 25, "median": 40, "q3": 60, "max": 80 }`。
- 区间图和甘特图：`value`、`value2` 表示两端数值；区间端点自动排序。
- 动态条形图：`{ "name": "咖啡", "value": 789, "period": "一月" }`；也接受 `种类`、`销量`、`月份`。
- 路径动画：`{ "x": 0.2, "y": 0.8 }`，坐标使用组件内 0–1 的比例。
- 旭日图：`{ "name": "产品", "value": 60, "children": [{ "name": "A", "value": 35 }] }`；目前绘制两层。

普通图表最多绘制 30 条；日历热力图最多绘制 371 条，桑基图最多读取 100 条连线，动态条形图最多读取 5000 条数据。动画只在播放状态下触发持续重绘。旧场景未保存配置时使用渲染器默认值。

## 图表交互

预览和播放页根据当前帧绘制的图形识别数据项，支持柱和条形、折线段、面积、扇区、双轴和 3D 图表，也支持桑基图节点与连线、旭日图子扇区、动态条形图等特殊预设。悬浮提示可独立关闭，有图例的图表可按系列或类别切换显示。旋转和入场动画中的图形仍按实际位置命中。

图表“点击元素”规则可选“所有项”或指定数据项。“修改设置”可选多个组件和要改的属性，也可以按名称筛选指定组件或当前组件的子组件。可修改的图表设置随目标类型变化，包含当前图表支持的颜色、图形、图形文本、坐标轴、图例和提示设置。动态值可直接读取点击值、系列、行索引或原始行字段，也可用 `{:payload.value}` 和 `{:项目参数名}` 拼接文本或进行四则运算。项目参数随项目文件和发布包导出。

“Payload 写入内置数据源”和事件动作在参数留空时使用当前数据项，包含 `name`、`value`、`series`、`index` 和原始 `row`。外部页面也可监听冒泡的 `dw:chart-item-click` 事件。

指定数据项可打开前景看板中的弹窗。弹窗的关闭、取消和确定按钮会关闭当前弹窗，也可分别触发弹窗内元素交互。

交互动作提供“播放入场动画”：支持淡入、四个方向进入、缩放、缓动、动画叠加、延时与时长。“之后”按上一组动作的实际完成时间执行，退出预览、离开页面或销毁播放页时取消尚未执行的动作。动画状态只保存在运行时，不修改组件原始数据。

图表的自定义状态可单独保存图表配置，交互切换状态时使用该状态的设置。切回默认状态会恢复默认图表配置。

## 当前边界

当前仍有山海鲸专有动作参数、默认离场动画、其余条件样式、专用图表缩略轴，以及各图表专有辅助线选项需要对齐。部分图表的排名文本和具体字体仍未完整对齐。提示框背景模糊、辅助线标签的完整字体样式，以及部分专用图表的悬浮行为仍未对齐；横向辅助线标签目前显示所选分类的首个可见系列值。堆叠图、区间图、图形柱状图和双轴图目前仍将负数按零绘制，也尚不支持手动数值轴范围；对数轴和时间轴尚未接入。动态值公式支持字段引用、文本拼接和四则运算。甘特图使用数值区间，旭日图支持两层，3D 图表使用二维投影和挤出近似。`Echarts二开基础示例`展示内置河流图形，ECharts 自定义代码尚未接入。数据字段映射使用项目的数据绑定功能。

## 验证

前端测试覆盖 85 个预设、实例隔离、配置撤销、导入和实时数据替换；Rust 看板测试比较多类图表配置变化、特殊数据和动画时刻的实际像素输出。运行：

```sh
cd frontend
pnpm exec vitest run src/tests/chartProperties.test.ts src/tests/chartPresets.test.ts src/tests/kitCatalog.test.ts src/tests/chart3d.test.ts src/tests/liveData.test.ts src/tests/boardRedraw.test.ts
pnpm test:board:wasm
cd ../engine-rs
cargo test -p native-probe --test board
```
