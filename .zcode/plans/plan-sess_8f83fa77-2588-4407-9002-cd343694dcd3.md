# 图层树管理：右键菜单（root≠子节点）+ 右侧抽屉式配置面板

## Context

对标山海鲸图层管理页（workspace.shanhaibi.com/#/project/layer），为 data-wind 编辑器实现左侧图层菜单管理：
1. **左键点击节点** → 右侧**抽屉滑出**该节点的配置菜单（替代现在的常驻右列）
2. **右键点击节点** → 上下文菜单；**root 菜单 ≠ 子节点菜单**
3. **看板图层与 3D 组件图层两种模式都要实现**

现有基础（探索已确认，全部复用）：
- 左树已有：`LeftPanel.tsx` `SceneTreePanel`（Semi Tree，双模式，树 value 无选中时回落到虚拟根 `@board`/`@scene`）
- 自绘右键菜单基建已有：`ContextMenu.tsx` + `state/contextMenu.ts` + `SceneContextMenuHost.tsx::buildSceneContextMenu`（挂载于 WorkspacePage.tsx:724，目前只由画布触发）
- 全部树操作 SceneOp 已存在（rename/remove/batch/reorder/group/reparent/paste…），无需动 Rust/FlatBuffers
- root 配置内容已有现成组件：`BoardProperties`（看板设置）、`SceneSettings`（场景设置），现在渲染于 PropertiesPanel 无选中分支
- Semi Tree 原生支持 `onContextMenu?: (e: MouseEvent, node: TreeNodeData) => void`（已核实 node_modules 接口）
- `pasteSelection`/`selectAll` 已有（`sceneActions.ts:85/94`）；Esc 清选区在 `WorkspacePage.tsx:435`

用户三个决策未答复，按推荐执行：**覆盖式抽屉**、**完整版 root 菜单**、**画布选中同样滑出抽屉**。

## 实现

### 1. 左树右键接线 — `frontend/src/components/LeftPanel.tsx`

- Tree 加 `onContextMenu={(e, node) => …}`：取 `String(node.key)`；
  - 真实节点：若不在当前多选中 → 先 `post({type:"select",id})`，再 `openSceneContextMenu(e.clientX, e.clientY, key)`（与画布右键同库）
  - 虚拟根（`@board`/`@twin`/`@scene`/`@sky` 等 `@` 开头）：直接 `openSceneContextMenu`（菜单项自会处理动作）
- `onSelect` 扩展：`@board`/`@scene` → 调新 prop `onSelectRoot(id)`（不 post select）；`@twin` → 保持现有 `setEditing(true)`
- 新增 prop：`onSelectRoot: (id: string) => void`

### 2. root 专属菜单 — `frontend/src/components/SceneContextMenuHost.tsx`

`buildSceneContextMenu` 入口按 `targetId.startsWith("@")` 分支到新函数 `buildRootContextMenu(targetKey, ctx)`。完整版菜单：

- **`@board`（看板根，label=boardName）**：页面设置（=选中 root，抽屉显示 BoardProperties）│ 重命名子大屏 / 添加空白子大屏 / 复制当前子大屏 / 删除子大屏（子大屏≤1 禁用）│ 全选组件（`selectAll(false)`）/ 粘贴（剪贴板空禁用，复用 `pasteSelection`）
- **`@scene`（3D 场景根）**：场景设置（抽屉显示 SceneSettings）│ 全选对象（`selectAll(true)`）/ 粘贴
- **3D 固定分层** `@sky/@camera/@models/@plants/@terrain/@markers/@shapes/@lights`：全选该层 / 显示该层 / 隐藏该层（按 LeftPanel 同款类型过滤算出层内节点 ids → `selectMany` / `batch show/hide`；空层禁用）
- **`@twin`**：进入 3D 编辑

root 动作需要 WorkspacePage 本地函数（子大屏管理、setEditing、选 root）：给 `SceneContextMenuHost` 增加可选 prop `rootActions?: { openRoot:(id:string)=>void; edit3D:()=>void; renamePage:()=>void; addPage:(dup:boolean)=>void; deletePage:()=>void; canDeletePage:boolean }`，由 WorkspacePage 接线（沿用其现有 `createBoardPage`/`renameActiveBoardPage`/`deleteActiveBoardPage`）。右键真实节点的既有菜单**原样不动**。

### 3. 抽屉化右侧面板 — `PropertiesPanel.tsx` + `WorkspacePage.tsx` + `app.css`

- `PropertiesPanel` 新增 props：`rootNode?: "@board"|"@scene"|null`、`onClose?: () => void`
  - `rootNode` 存在 → 渲染根配置：标题「看板设置」→ `<BoardProperties/>`，标题「场景设置」→ `<SceneSettings/>`（即现有无选中分支的内容搬进 root 分支），其余节点/多选逻辑不变
  - header 右侧加 ✕ 关闭按钮（调 `onClose`）
- `WorkspacePage`：新增本地 state `rootNodeId`（同 `boardSelected` 管理方式）：
  - 任何真实选中发生时清空（Tree onSelect 真实节点、画布 onPick、selectAll 等——实现时在 `selectedId/selectedIds` 变化的订阅处统一复位，含 WorkspacePage.tsx:305 的 bridge.subscribe 回写）
  - Esc 处理（:435）与点空白（setBoardSelected(false) 处）一并清 `rootNodeId`
  - 抽屉开合：`const drawerOpen = Boolean(state.selectedId || state.selectedIds.length || boardSelected || rootNodeId)`
  - `<PropertiesPanel>` 挂载点（:661）移入新容器 `aside.editor-drawer ${drawerOpen?"is-open":""}`（覆盖式：绝对定位于 `.editor-body-row` 右缘，需给该行加 `position:relative`；`translateX(100%)↔0` 过渡 + 阴影；开合状态由 CSS 类驱动）
- **关闭语义**：✕ / Esc / 点空白 = 清全部选中（`post select null` + `setBoardSelected(false)` + `setRootNodeId(null)`）→ 抽屉滑回
- 底栏 `.board-statusbar` 不动（覆盖式不挤压布局）
