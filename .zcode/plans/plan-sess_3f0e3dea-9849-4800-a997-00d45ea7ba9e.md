# 从山海鲸同步「套件」分类

## Context

项目一直在按山海鲸对齐编辑器(已有 docs/property-panel-sync.md、control-widgets-sync.md)。本次对照截图同步「套件」:山海鲸看板素材面板的「套件」分类下有子分类 chips(全部/装饰/图表/交互组件/图标)和套件卡片(返回按钮、环形图-2、基础信息-2、进度条、全览按钮-2、菜单-3、图例、指标卡组-1 等),点击一次插入一组预制组件。

现状(探索结论):
- 看板面板 `frontend/src/components/BoardComponents.tsx` 按 category 字符串分发到各 palette,卡片点击 `getSceneBridge().post({type:"add", node})` 插入;`boardCategoryCounts` 是静态常量;`boardCategories` 在 `frontend/src/pages/WorkspacePage.tsx:28`。
- worker 已有 `paste`/`appendScene` 批量插入原语(`frontend/src/workers/sceneModel.ts:362,578`),`copyNodes(nodes,false)` 可重映射 id 且不加偏移(`:270`)。
- 缩略图惯例:图表/文本用运行时真实渲染(BoardComponents 内 ChartThumb/TextThumb 复用 WidgetContent/chartSvg),套件沿用此思路。
- icon-park 有 `Layers` 图标可作套件 rail 图标(已验证 node_modules 存在)。

## 改动

### 1. 新建 `frontend/src/data/kitCatalog.ts`(仿 textCatalog.ts)
- `KitPieceSpec { kind; name?; widget?; data?; size?; color?; offset: [number,number] }`,offset 为相对套件原点的坐标。
- `KitCatalogEntry { id; label; category: "装饰"|"图表"|"交互组件"|"图标"; pieces: KitPieceSpec[] }`。
- `kitNodes(entry, origin={x:80,y:80}): SceneNode[]`:每片经 `widgetNode(kind)` + 覆盖字段生成,position=origin+offset,id 用 `kit-<entryId>-<i>`(worker 端会重映射)。
- 首批 10 个套件,label 对齐截图:返回按钮(图标)、环形图-2(图表)、基础信息-2(装饰,天气+日期+时钟横排)、进度条(交互组件)、全览按钮-2(交互组件)、菜单-3(交互组件,list)、图例(装饰,渐变条 shape+3 文本)、指标卡组-1(装饰,白底指标卡)、指标卡组-2(装饰,3 张白卡横排)、指标卡-1(装饰,指标+数据变化)。只用 metric/progress/pie/button/list/text/clock/shape/weather/dataChange 等 DOM 渲染稳定的 kind(不用 map/iframe/video,缩略图不需要地理数据)。
- `kitCategories` + `usedKitCategories`(惯例同 chartCatalog)。

### 2. `frontend/src/workers/sceneModel.ts`:新 op `insertKit`
- SceneOp 联合加 `| { type: "insertKit"; nodes: SceneNode[] }`。
- case:pushUndo → `copyNodes(op.nodes, false)`(重映射 id、retarget interactions、无粘贴偏移)→ push 进 tree → `selectedIds` = 全部新节点、selectedId=末位。多选插入后第一次拖动即可整组移动(transformSelection 多选路径),贴合山海鲸套件体验;用户可再 Ctrl+G 组合。
- `labels` 加 `insertKit:"插入套件"`;`:624` 的不清空选区列表加入 `insertKit`。
- 单片套件不走此 op,直接复用 `add`。

### 3. `frontend/src/components/BoardComponents.tsx`
- `boardCategoryCounts` 加 `套件: kitCatalog.length`,「全部」计数加上。
- `KitThumb`:kitNodes 以 origin(0,0) 布局 → 计算包络宽高 → 外层 `.chart-thumb` 内绝对定位渲染每片 `WidgetContent`(preview=false,now 用 useMemo 固定),`transform: scale()` 缩放进缩略框,新 CSS 类 `.kit-thumb-inner`(transform-origin:0 0)+外层 overflow hidden。
- `KitCard`:onClick → 1 片 post `add`,多片 post `insertKit`。
- `KitPalette`:chips(usedKitCategories)+ `.chart-grid`,搜索过滤 label/category。
- `ComponentPalette`:分发 `套件` → KitPalette;「全部」视图追加套件 section(地图之后)并纳入空态判断。

### 4. `frontend/src/pages/WorkspacePage.tsx`
- `boardCategories` 在「地图」与「3D」之间加 `{ label: "套件", icon: <Layers {...railIcon}/> }`,import Layers(@icon-park/react)。

### 5. `frontend/src/styles/app.css`
- `.kit-thumb` 系列样式(对齐现有 chart-thumb 暗色卡风格)。

### 6. 测试 `frontend/src/tests/kitCatalog.test.ts`(仿 textCatalog.test.ts / scene.test.ts)

- sceneModel:`insertKit` 后树增长、id 重映射、全部新节点被选中、undoLabel 为「插入套件」、undo 可还原。
