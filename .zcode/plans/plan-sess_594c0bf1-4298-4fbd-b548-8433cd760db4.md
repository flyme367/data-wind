# 全量 FlatBuffers 化 wasm↔前端协议

## Context

当前 3D 引擎出方向（`take_response`，DWCR v1）已是 FlatBuffers，其余 **14 个 wasm 边界方法仍是 JSON 字符串**。目标：整个 wasm↔前端边界全部走 FlatBuffers（版本已统一 pin 25.9.23，无新依赖），行为不变。

迁移清单（来自代码盘点）：
- **入方向**：`Engine::set_mode/set_hud/set_environment/set_selections/sync_scene`（lib.rs）、`SoftwareCanvas::frame`（software.rs，**逐帧**热路径）、`BoardCanvas::sync_scene/set_value/set_geojson/frame/snapshot`（board_canvas.rs，Clock 逐帧）
- **出方向**：`BoardCanvas::take_events`、`hit_test`（**每次 mousemove**）、`supported_kinds`

## Schema：单文件追加（protocol/command_response.fbs）

保持单 schema 文件、命名空间 `DataWindProtocol`、root_type/`DWCR`/现有表**全部不动**（文件头已声明 append-only 规则）。追加：

```
enum Mode:ubyte {Editor, Login}          enum BoardAction:ubyte {Change, Focus, Open, Media, Upload, ColorPicker}
table JsonNull{}  JsonBool{value:bool}  JsonNumber{value:double}  JsonString{value:string}
table JsonArray{items:[JsonValue]}  JsonEntry{key:string(req); value:JsonValue}  JsonObject{entries:[JsonEntry]}
union JsonPayload{...六成员}             table JsonValue{payload:JsonPayload}
table BoardEvent{id:string(req); kind:string; action:BoardAction; value:JsonValue}
union EventPayload += BoardEvent   (追加第7成员，旧读取端自动跳过 ✓)
table StringList{items:[string]}         table HitResult{id:string(req); handle:string; control:bool}
table SetMode{mode:Mode}  SetHud{grid,flylines,stats:bool}
table SetEnvironment{background:Color4; ground:Color4; daylight:float; fog_distance:float}
   （注意：现有 Color4 不能复用 Rgba——Rgba 是 ubyte 0-255，前端传 0-1 float）
struct Color4{r,g,b,a:float}
table Instance{id:string(req); kind:string(req); pos:Vec3; size:Vec3; rot_y:float;
               rotation:[float]; color:Vec3; locked:bool(optional); to:[float]; model_id:string}
table SceneUpdate{instances:[Instance](req)}   table Camera{target:Vec3; yaw,pitch,dist:float}
table RenderOptions{grid:bool; selected_id:string; selected_ids:[string]; time:float;
                    background:string; daylight:float}   // ""/0 哨兵=缺省，schema 注释说明
table SoftwareFrame{instances:[Instance](req); camera:Camera(req); options:RenderOptions(req)}
table WidgetStyle{...23字段，与 Rust WidgetStyle 一一对应}
table BoardNodeWire{id:string(req); name; x,y,width,height,rotation:float; color:string;
                    locked:bool; widget:WidgetStyle; data:JsonValue}
table BoardSync{width,height:float; preview:bool; selected:[string]; nodes:[BoardNodeWire]}
table SetValue{id:string(req); value:JsonValue}   table BoardClock{time:string; year,month,day,first_weekday,days:uint; now:double}
table Ring{points:[float]}  GeoFeature{polygons:[[Ring]]; name:string; name_zh:string}
table GeoJsonDocument{features:[GeoFeature]}
union CommandPayload{SetMode,SetHud,SetEnvironment,SetSelections,SceneUpdate,SoftwareFrame,BoardSync,SetValue,BoardClock,GeoJsonDocument}
table CommandRequest{protocol_version:ushort; payload:CommandPayload(req)}
```

设计要点：
- **入方向走信封**（CommandRequest + union）：Engine/BoardCanvas/SoftwareCanvas 存在**同名方法**（sync_scene 两处、frame 两处），信封的 payload_type 校验天然防串路由；请求缓冲**不带 identifier**（单文件只能有一个），靠 `flatbuffers::root::<T>`（25.9.23 已确认存在，走 verifier）+ version==1 + payload_type 匹配。
- **出方向复用 DWCR CommandResponse 信封**：board 事件作为 union 追加成员，`dispatchCommandResponse` 一套解码器两处复用；空帧=0 字节约定一致。
- **JsonValue 泛型递归 union**：`BoardNode.data`、`set_value`、`BoardEvent.value` 本质是无 schema 的 JSON（table 表格行任意键已确认），用泛型值编解码；Rust 侧在边界处一次性还原成 `serde_json::Value`，**board 内部 25+ 处消费点（options()/number()/charts/controls）零改动**——wire 二进制化，serde_json 退为 Rust 内部表示。
- `set_geojson` 同理：TS 端对网络返回 JSON.parse 一次（源头就是 JSON，不可避免）→ 编码 typed GeoJsonDocument → Rust 侧适配器重建 maps.rs 期望的 Value 形状，maps.rs 零改动。

## 实施步骤

### 1. flatc + schema + codegen
- 下载官方 flatc 25.9.23 prebuilt（macOS x64，GitHub release），放 `tools/` 并 gitignore；`FLATC=... pnpm generate:protocol`
- **generate-protocol.mjs 零改动**（walk 整个输出目录，新表自动带出）
- 提交两端生成代码；`pnpm check:protocol` 过

### 2. Rust 入方向（解码）
- `protocol.rs`：`decode_request(bytes) -> Result<wire::CommandRequest>`（root+version 校验）；JsonValue→`serde_json::Value` 还原器
- `lib.rs:569/609/871/921/965` → `&[u8]`，保持现有错误语义（sync_scene 坏包→Error 事件，其余静默 no-op）；更新 /// 文档
- `software.rs` frame 解码 SoftwareFrame→内部 SoftwareInput（结构不变）
- `board_canvas.rs` sync_scene/set_value/frame/snapshot/set_geojson → bytes；`board/mod.rs` BoardDocument 解码（JsonValue→Value 适配）；`maps.rs` 头部加 wire→Value 适配函数，消费函数不动
- `board/mod.rs`：`BoardEvent.action: String` → `BoardAction` 枚举；`controls.rs`（~6 处）/`widgets.rs` 发射点改枚举

### 3. Rust 出方向（编码）
- `common.rs` EngineEvent 增加 `BoardEvent{id,kind,action,value}` 变体；`protocol.rs` encode_event 加对应 arm（Value→JsonValue 编码器）；BoardCanvas 排空时把 Vec\<BoardEvent\> 转成 EngineEvent 走既有 `ResponseEncoder`
- `board_canvas.rs`：`take_events()->Result<Vec<u8>>`、`hit_test()->Result<Vec<u8>>`（局部 builder，finish 无 identifier，空=无命中）、`supported_kinds()->Vec<u8>`（StringList）；删 Hit/BoardEvent 的 serde Serialize

## 风险与已知取舍
- 生成类 `BoardEvent` 与 boardCanvas 本地接口重名 → 改名本地接口
- `Instance` 必填字段在 flatbuffers 里缺省=0（serde 缺失=报错）：TS 编码器总是写全，语义等价，文档记录
- serde_json 保留为 Rust 内部表示（边界适配器），是刻意决策，后续可做 typed BoardNode.data 二期
- wasm ABI 破坏性变更：同仓原子发布（wasm+胶水+前端一起），无兼容包袱
