# 同步山海鲸「地图」分类：16 项目录 + 图片卡片 + 右侧面板 1:1

## Context

用户要求把山海鲸 4.7.13 素材库「地图」分类 1:1 同步到 data-wind：子分类 chips（全部/轮廓地图/瓦片地图/三维地图）、16 个组件的图片式卡片，以及每个组件右侧属性面板配置项深度复刻。已实机盘点（workspace.shanhaibi.com，用户项目，全程未保存、已撤销还原至 4/4 组件）：

**16 项清单（实测）**：轮廓地图 6 项 = 中国地图 / 世界地图 / 美国地图 / 自定义地图 / 世界地图一 / 世界地图二；瓦片地图 7 项 = GIS卫星地图（卫星）/ GIS电子地图（基础）/ GIS地图（黑金/蓝黑/草绿/浅蓝/深蓝）；三维地图 3 项 = 3D GIS底座 / 科技风3D地图 / 写实风3D地图。

**已盘全面板**（轮廓家族 6 项全量）：基本设置（不透明度/鼠标穿透/渲染模式 canvas/地图投影方式；中国地图多「地图区域(全国)+地图下钻+显示返回按钮」、美国地图多「行政编码」、自定义地图多「选择geojson文件」）；底图层（填充类型 颜色/图片、默认颜色、高亮颜色、选中时的颜色、分界线颜色、分界线粗细 px、外轮廓线颜色/粗细/发光强度/发光颜色、分界线类型 实线/点线、阴影大小/颜色、区域名称开关、强制显示所有区域名称开关、名称字体 字体/字号/加粗/倾斜/下划线/删除线）；呼吸点层（显示名称、呼吸点形状 圆形、最小/最大半径 px、呼吸点颜色）；热力/柱状/路线/飞线/标记层（空数据时不渲染字段）；展示设置（播放动画、触发数据联动、动画延迟时长、单个滚动持续时长、循环播放动画、循环间隔 秒）；公共分区（大小&位置/响应式布局/边框/背景/组件封面）。世界地图一/二实为**分组面板**（组内含地图+背景），组面板多 内部组件布局(静态/流式)/状态跟随/选中互斥/显示滚动条/滚轮缩放 + 允许缩放。

**边界结论（用户未答问题，按推荐默认，写入 docs）**：① 三维地图 3 项是 3D 场景组件，看板渲染器为 2D egui 画不了 → 不进看板目录（13 项），后续作为 3D GIS 素材库模板单独同步；② 现有 6 个数据地图组件（区域/点/飞线/热力/轨迹/柱状）保留为地图分类的额外 chip「数据图层」，旧项目不受影响；③ GIS 瓦片地图为离线矢量风格化主题渲染（非在线瓦片，无网络/key 依赖），docs 记录视觉偏差；④ 卡片缩略图自产 webp（不拷贝山海鲸图片，符合 webp q60 政策）；⑤ GIS 家族与 3D 家族的面板细目在实施第一步用已验证的浏览器路径补盘（rail 地图 JS 点击 → 搜索框过滤 → Playwright 双击 → 撤销还原；已知坑：合成 dblclick 事件被过滤、虚拟列表 scrollIntoView 失效、截图在 WebGL 场景下超时只能用 DOM 快照）。

## 实施步骤

### 1. 补盘 GIS 瓦片家族面板（浏览器）
用已验证 recipe 插入 GIS卫星地图（卫星）与 GIS地图（黑金），DOM 快照盘点面板字段（预期：瓦片底图设置/中心点/缩放级别/主题样式），撤销还原，不保存项目。

### 2. 协议与地理数据
- `protocol/command_response.fbs` GeoFeature 加 `dataset:string`（world/china），flatc 重新生成（`tools/` + `frontend/scripts/generate-protocol.mjs`）。
- `frontend/src/engine/commands.ts` encodeGeoJsonDocument 带 dataset；Rust `board/maps.rs` geojson_value_from_wire 透传。
- 下载中国省界 GeoJSON（DataV 开放数据）→ `frontend/public/gis/china-provinces.geojson`，`ATTRIBUTION.md` 记录来源；`boardCanvas.ts` loadGeojson 与 `mapSvg.ts` loadWorldGeo 合并 world+china 两数据集。

### 3. 目录与卡片（frontend/src/data/mapCatalog.ts + BoardComponents.tsx）
- chips：全部 / 轮廓地图 / 瓦片地图 / 数据图层（usedMapCategories 过滤）。
- 13 个新 entry：轮廓 6 项 kind=mapOutline（世界地图一/二为分组卡：mapOutline 节点 + 背景装饰节点整组插入，仿 kitNodes/insertKit）；瓦片 7 项 kind=mapTile + theme preset（卫星/基础/黑金/蓝黑/草绿/浅蓝/深蓝）；数据图层 chip 放旧 6 项。
- 卡片改图片式（`<img className="twin-thumb-img">`，TwinCard 模式），缩略图来源见步骤 6。

### 4. 数据模型与 TS 渲染
- `editor.ts`：新 kind `mapOutline`/`mapTile`（widgetLabels、controlPresets 含 `data.map` 配置与主题 preset、默认尺寸 1920×1080 缩放为合理看板尺寸）。
- `mapSvg.ts`：区域子集渲染（world/china provinces/usa/自定义 geojson）、主题配色（7 个瓦片主题 + 轮廓区域主题）、省界/国界分界线样式（实线/点线）、外轮廓发光、区域名称标注、呼吸点层。SVG 端与 Rust 端同参数同视觉。

### 5. 属性面板 1:1（WidgetProperties.tsx）
mapOutline/mapTile 路由到专用面板，分区按实测复刻：基本设置（地图投影方式/地图区域/地图下钻/行政编码/选择geojson文件 按 kind 显示）→ 底图层（全量字段，落 `node.data.map`）→ 呼吸点层 → 展示设置 → 大小&位置/边框/背景/组件封面 公共区。分组卡（世界地图一/二）额外显示 内部组件布局 等组配置。面板配置存 `node.data`（运行时覆盖走 JSON 通路，不动线上协议）。

### 6. 缩略图产图（frontend/scripts/generate-map-thumbs.mjs）
Headless Chrome 渲染本地页面（按 entry 用 mapSvg 画各主题地图）→ 截图 → `lib-webp.mjs` encodeMinWebp → `frontend/public/reference/map-*.webp`。禁止直写 png/jpg。

### 7. Rust 双端（engine-rs/data-wind-cpu/src/board/）
- `mod.rs` WIDGET_KINDS 加 mapOutline/mapTile；`widgets.rs` match 分支（标题+paint_map 复用）。
- `maps.rs`：按 dataset/区域过滤要素、主题配色、省界、区域名称标注、呼吸点动画（clock 驱动）、自定义 geojson（node.data.geojson 内嵌解析）。
- cargo test → `pnpm build:engine` 双变体（cpu + cpu-parallel）。

### 8. 测试与文档
- `mapCatalog.test.ts` 更新（新目录/chips/主题 preset 断言）+ Rust 侧既有 WIDGET_KINDS 比对测试自动覆盖。
- 新建 `docs/map-components-sync.md`：16 项清单、三家族面板盘点全记录、四条边界结论、缩略图产图方式。
